## Key Concepts

### 1. Design AI and Agents for Business Solutions

**Agent Types**
- **Task Agents**: Automate specific workflows
- **Autonomous Agents**: Make independent decisions
- **Prompt and Response Agents**: Conversational interfaces

**Copilot Customization in Dynamics 365**
- Business terms definitions
- Industry-specific vocabulary
- Custom prompts and responses
- Connector integration

**Copilot Studio Topics**
- Trigger phrases
- Conversation flow
- Entity extraction
- Fallback handling
- Generative AI orchestration

### 2. Design Extensibility of AI Solutions

**Azure AI Foundry Custom Models**
- Fine-tuned models
- Custom endpoints
- Model versioning
- A/B testing

**Model Context Protocol (MCP)**
- Standardized tool integration
- Cross-platform compatibility
- Resource management
- Security controls

**Computer Use in Copilot Studio**
- Automate web and app interactions
- Screen understanding
- Action execution
- Process automation

**Agent Behaviors**
- Reasoning modes
- Voice interactions
- Personality configuration
- Response formatting

### 3. Orchestrate Configuration

**Dynamics 365 AI Features**
- Sales: Lead scoring, opportunity insights
- Service: Case suggestions, knowledge recommendations
- Finance: Cash flow predictions, inventory optimization
- Supply Chain: Demand forecasting, quality predictions

**Microsoft 365 Agents**
- Teams agents
- SharePoint agents
- Outlook integrations

**Power Platform AI**
- AI Builder models
- AI Hub
- Intelligent automation
