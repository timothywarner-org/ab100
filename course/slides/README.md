## Slide Design Guidelines

- **Title slide**: Segment name, instructor, time
- **Objective slides**: 2-3 per segment
- **Content slides**: Diagrams > bullets
- **Demo markers**: Clear "DEMO" indicator
- **Exercise slides**: Instructions + timer
- **Exam tips**: Highlighted callouts
- **Resources**: Links at section end
