# Design AI agents for business solutions

Learn to design AI agents tailored to business needs using Dynamics 365 and Copilot.

- Module type: Module (21 units)
- Level: Advanced
- Role: Solution Architect
- Products: Microsoft 365 Copilot, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio, Dynamics 365

## Learning objectives

After completing this module, you will be able to:

- Apply Responsible AI principles to AI agent design.
- Configure business terms and customize Copilot in Dynamics 365.
- Design custom connectors and integrate AI agents with Dynamics 365 Contact Center.
- Build task-focused and autonomous agents using Microsoft Copilot Studio.
- Implement prompt-driven conversational agents with adaptive responses.

## Prerequisites

- Familiarity with Dynamics 365 and AI concepts.
- Basic understanding of Microsoft Power Platform and Microsoft Dataverse.

20. Module assessment.
21. Summarize AI agent design for business solutions.

## AB-100 mapping

This is the central **Design AI-powered business solutions** module (Design domain, 25-30%). It covers the
design surfaces tested heavily on AB-100: task, autonomous, and prompt-driven agent patterns in
*Microsoft Copilot Studio*; Dynamics 365 Customer Service, Sales, and Contact Center customization; and the
"Apply the Microsoft Power Platform Well-Architected Framework to intelligent application workloads"
objective. Foundry tool selection and topic design (including fallback) are recurring scenarios.
