# Design responsible AI security, governance, risk management, and compliance

Learn to design secure, governed, and compliant AI systems that align with organizational policies and
Responsible AI principles.

- Module type: Module (11 units)
- Level: Advanced
- Role: Solution Architect
- Products: Microsoft 365 Copilot, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio, Dynamics 365

## Learning objectives

After completing this module, you will be able to:

- Design AI systems that balance innovation with accountability.
- Apply identity, access control, and data governance to secure AI agents.
- Implement observability and threat protection for AI solutions.
- Translate compliance requirements into technical controls.
- Mitigate vulnerabilities across prompts, models, and workflows.

## Prerequisites

- Working knowledge of Microsoft Entra ID, Azure RBAC, Azure monitoring, data governance concepts, and
  Microsoft Copilot Studio administration.

## Units

1. Introduction.
2. Design security agents for Microsoft clouds.
3. Design governance models for AI agents.
4. Design model security for responsible AI.
5. Analyze AI vulnerabilities and mitigations for prompt manipulation.
6. Review solution adherence to Responsible AI principles.
7. Validate data residency and movement compliance.
8. Design access controls for grounding data and model tuning.
9. Design audit trails for changes to models and data.
10. Module assessment.
11. Summary.

## AB-100 mapping

This module aligns to the **Deploy AI-powered business solutions** domain (40-45%) and is the primary
source for the security and governance half of Deploy that Tim teaches in course hour 4. It covers the
"Review solution for adherence to responsible AI principles", prompt-manipulation mitigation, data residency
and movement, audit trails, and access controls for grounding data and model tuning. Pair with module 10
(ALM) and module 8 (monitoring) to complete the Deploy domain.
