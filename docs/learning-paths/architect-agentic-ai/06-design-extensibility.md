# Design extensibility of AI solutions

Learn to design scalable, secure, and customizable AI solutions using Microsoft platforms.

- Module type: Module (10 units)
- Level: Advanced
- Role: Solution Architect
- Products: Microsoft 365 Copilot, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio, Dynamics 365

## Learning objectives

After completing this module, you will be able to:

- Design scalable and secure AI solutions using Microsoft platforms.
- Leverage custom models in Microsoft Foundry.
- Design and operationalize agents in Microsoft 365 Copilot.
- Extend agent capabilities using Microsoft Copilot Studio and Model Context Protocol (MCP).
- Apply governance and lifecycle management for AI solutions.

## Prerequisites

- Familiarity with AI concepts and enterprise architecture.
- Basic understanding of Microsoft 365 and Dynamics 365 platforms.

## Units

1. Introduction.
2. Design AI solutions with custom models in Microsoft Foundry.
3. Design agents in Microsoft 365 Copilot.
4. Design extensible agents in Microsoft Copilot Studio.
5. Design extensible agents using MCP in Microsoft Copilot Studio.
6. Design agents to automate tasks in apps and websites with Computer Use in Microsoft Copilot Studio.
7. Design agent behaviors in Microsoft Copilot Studio (reasoning and voice mode).
8. Optimize solution design for agents in Microsoft 365 (Teams and SharePoint).
9. Module assessment.
10. Summary.

## AB-100 mapping

This module aligns to the **Design AI-powered business solutions** domain (25-30%) and is the primary source
of AB-100 content on extensibility surfaces: custom Microsoft Foundry models, MCP-based tool calling,
Computer Use, reasoning, voice mode, and Microsoft 365 Copilot extensibility through Microsoft Teams and
SharePoint. AB-100 explicitly tests working knowledge of MCP, so unit 5 is high priority.
