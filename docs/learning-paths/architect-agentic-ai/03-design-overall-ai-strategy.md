# Design overall AI strategy for business solutions

Learn to design an enterprise AI strategy using the Cloud Adoption Framework for Azure, aligning AI agent
lifecycle with business goals for operational excellence.

- Module type: Module (19 units)
- Level: Advanced
- Role: Solution Architect
- Products: Microsoft 365 Copilot, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio, Dynamics 365

## Learning objectives

After completing this module, you will be able to:

- Map the Cloud Adoption Framework's AI adoption phases to the AI agent lifecycle.
- Design an enterprise-ready operating model for AI agents.
- Select and apply Microsoft platforms for AI solutions.
- Use checklists to transition AI workloads from proof of concept to production.

## Prerequisites

- Familiarity with the Cloud Adoption Framework for Azure.
- Basic understanding of AI agent lifecycle and governance.

## Units

1. Introduction.
2. Implement AI adoption process with the Cloud Adoption Framework for Azure.
3. Design AI agents for business solutions.
4. Design a multi-agent solution.
5. Develop use cases for prebuilt Microsoft 365 Copilot agents.
6. Define solution rules and constraints for AI components.
7. Determine generative AI knowledge sources for agents built in Microsoft Copilot Studio.
8. Determine when to build custom agents or extend Microsoft 365 Copilot.
9. Determine when custom AI models should be created.
10. Provide guidelines for creating a prompt library.
11. Develop use cases for customized small language models.
12. Provide prompt engineering guidelines and techniques.
13. Identify key business user roles for AI workloads.
14. Evaluate regional and local AI data regulation compliance requirements.
15. Include elements in a Microsoft AI Center of Excellence.
16. Design AI solutions using multiple Dynamics 365 apps.
17. Design user prompt training for AI solution adoption.
18. Module assessment.
19. Summary.

## AB-100 mapping

This is the heaviest **Plan AI-powered business solutions** module (Plan domain, 25-30%). It directly maps
to "Implement the AI adoption process from the Cloud Adoption Framework for Azure", "Include the elements of
the Microsoft AI Center of Excellence", and "Determine when to build custom agents, extend Microsoft 365
Copilot, or use prebuilt agents". Several units (6, 7, 8, 9, 10, 11, 12, 17) also reach forward into the
Design domain by setting solution rules, knowledge sources, and prompt libraries before agents are built.
