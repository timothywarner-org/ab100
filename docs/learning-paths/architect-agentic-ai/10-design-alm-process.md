# Design ALM process for AI-powered business solutions

Learn to design ALM processes for AI solutions, ensuring governance, security, and consistency across
environments.

- Module type: Module (9 units)
- Level: Intermediate
- Roles: Database Administrator, Developer, Administrator, Solution Architect, Technology Manager
- Products: Microsoft 365 Copilot, Microsoft 365, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio

## Learning objectives

After completing this module, you will be able to:

- Design ALM processes for AI components like datasets, prompts, and models.
- Establish governance, security, and monitoring across environments.
- Ensure consistent and compliant AI behavior from development to production.

## Prerequisites

- Familiarity with AI concepts and lifecycle management.
- Basic understanding of Microsoft technologies like Microsoft Copilot Studio, Dynamics 365, and Microsoft
  Foundry.

## Units

1. Introduction.
2. Design an ALM process for data used in AI models and agents.
3. Design an ALM process for Microsoft Copilot Studio agents, connectors, and actions.
4. Design ALM processes for Microsoft Foundry agents.
5. Design an ALM process for custom AI models.
6. Design an ALM process for AI in Dynamics 365 Finance and Supply Chain.
7. Design ALM processes for AI in Dynamics 365 apps (Customer Experience and Service).
8. Module assessment.
9. Summary.

## AB-100 mapping

This module aligns to the **Deploy AI-powered business solutions** domain (40-45%) and is a direct match for
the "Design the ALM process for Copilot Studio agents, connectors, and actions" and "Design the ALM process
for Microsoft Foundry agents" objectives. Each unit corresponds to a discrete component the architect must
manage across environments: data, agents, connectors, actions, custom models, and the Dynamics 365
application surfaces.
