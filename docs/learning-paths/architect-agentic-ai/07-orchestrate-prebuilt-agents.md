# Orchestrate configuration of prebuilt agents and apps

Learn to orchestrate, configure, and extend AI-driven experiences in Dynamics 365 and Microsoft 365 Copilot.

- Module type: Module (10 units)
- Level: Intermediate
- Roles: Database Administrator, Developer, Administrator, Solution Architect, Technology Manager
- Products: Microsoft 365 Copilot, Microsoft 365, Microsoft 365 Copilot Chat, Microsoft Power Platform,
  Microsoft Copilot Studio

## Learning objectives

After completing this module, you will be able to:

- Orchestrate AI features and Copilot agents across Dynamics 365 and Microsoft 365 applications.
- Design secure, compliant, and extensible AI solutions.
- Configure and operationalize prebuilt Copilot agents for finance, supply chain, sales, and service
  scenarios.
- Apply best practices for responsible AI, workflow integration, and success measurement.

## Prerequisites

- Familiarity with Dynamics 365 and Microsoft 365 applications.
- Basic understanding of AI and machine learning concepts.
- Experience with solution architecture and enterprise systems.

## Units

1. Introduction.
2. Orchestrate AI features in Dynamics 365 Finance and Supply Chain.
3. Design AI solutions for Dynamics 365 Customer Service.
4. Propose Microsoft 365 agents for business scenarios.
5. Orchestrate and configure Microsoft 365 Copilot for sales and service.
6. Propose Microsoft Power Platform AI features (AI hub).
7. Design interoperable agent experiences for Finance and Operations.
8. Recommend process knowledge sources for in-app help in Dynamics 365.
9. Module assessment.
10. Summary.

Note: the live Microsoft Learn module page lists units in a different visual order; the sequence above is
the canonical study order corresponding to the unit slugs.

## AB-100 mapping

This module straddles the **Design** and **Deploy** domains. The "propose" and "configure" units (4, 5, 6,
7) reinforce Design-domain orchestration and prebuilt-agent selection. The Dynamics 365 Finance, Supply
Chain, Customer Service, and Sales units feed the Deploy-domain implementation and operations bullets.
Pair this module with module 5 to cover the full agent design surface.
