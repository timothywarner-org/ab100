AB-100 Hour 3 POC Visual Brief

Foundry Agent Wrapped as MCP, Hosted on ACA, Governed by APIM

These Mermaid diagrams visualize the classroom POC in src/ without changing the solution. The story is intentionally simple: a public MCP endpoint, a gateway policy layer, a serverless container runtime, managed identity authentication, and an existing Microsoft Foundry project plus agent.

1. Overall Application Architecture

The deployable Azure stack is APIM, ACA, ACR, Log Analytics, and a user-assigned managed identity. The Foundry project and agent already exist outside the POC stack.

2. Runtime Request and Response Flow

The app uses plain JSON-RPC over HTTP. APIM validates the subscription key, rewrites the backend URI, and leaves the MCP body untouched.

Runtime
sequenceDiagram
  autonumber
  participant Client as MCP client
  participant APIM as API Management
  participant Policy as APIM inbound policy
  participant ACA as Container App
  participant MCP as FastMCP server
  participant MI as Managed identity
  participant Foundry as Microsoft Foundry
  participant Model as Model deployment

  Client->>APIM: POST /mcp with JSON-RPC and subscription key
  APIM->>Policy: Apply inbound policy
  Policy->>Policy: Rate limit 60 calls per 60 seconds
  Policy->>Policy: Rewrite backend path to /mcp
  Policy->>ACA: Forward request with 120 second timeout
  ACA->>MCP: Route POST /mcp
  MCP->>MCP: Dispatch method tools/list or tools/call
  alt tools/list
    MCP-->>Client: JSON-RPC result with ask_agent tool metadata
  else tools/call ask_agent
    MCP->>MI: DefaultAzureCredential requests token
    MI-->>MCP: Entra token for configured UAMI
    MCP->>Foundry: responses.create with model, instructions, and user question
    Foundry->>Model: Invoke model deployment
    Model-->>Foundry: Generated answer
    Foundry-->>MCP: Response object and output_text
    MCP-->>Client: JSON-RPC result with answer, agent id, model, response id
  end
Happy pathtools/list proves MCP reachability; tools/call proves Foundry reachability.
Failure pathMissing APIM key returns 401 before ACA is involved.
Latency pathSlow model or tool execution is bounded by APIM forward timeout.
