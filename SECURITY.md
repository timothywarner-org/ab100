# Security Policy

## Scope

This repository contains documentation, course materials, and markdown scaffolding for the **Agentic AI Business Solutions Architect** O'Reilly course and AB-100 study guide. There is no runtime application, no server component, and no handling of user data.

## Reporting a vulnerability

If you find a security concern — for example, a link to a compromised resource, an exposed credential accidentally committed to this repo, or a supply-chain issue in any tooling added later — please report it privately:

- Email **Tim Warner** at **tim@techtrainertim.com** with the subject line **"AB-100 security report"**.
- Include the affected file, commit SHA, and steps to reproduce.

Do **not** open a public issue for sensitive reports.

## Response expectations

- Acknowledgement within two business days.
- Triage and initial mitigation plan within five business days.
- Public disclosure (if warranted) only after a fix is in place.

## Responsible use

The course content references Microsoft AI services, prompt-manipulation defenses, and governance frameworks. Any code or configuration published here is educational. Validate security configurations against current Microsoft documentation and your organization's policies before production use.
